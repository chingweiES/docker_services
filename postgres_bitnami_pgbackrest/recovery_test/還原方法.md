# 還原

## 步驟

* 暫停postgres服務

1. bitnami 使用了自訂的初始化腳本和管理方式（如 repmgr 或特定的服務管理邏輯）。
由於 Bitnami 容器在啟動時會自動嘗試初始化資料庫，還原的第一步通常是確保容器處於運行狀態但「停止資料庫進程」，或者利用 環境變數 防止它自動覆蓋資料。

```shell
# 使用 Bitnami 內建指令停止 PostgreSQL
/opt/bitnami/scripts/postgresql/stop.sh
```

[global]
repo1-path=/var/lib/pgbackrest

repo1-cipher-type=aes-256-cbc
保留兩個完整備份在存儲中。
repo1-retention-full=2的數據。當新的增量備份創建時，pgbackrest 會自動刪除最舊的增量備份，以確保只保留七個增量備份在存儲中。
repo1-retention-diff=7

process-max=4
compress-type=lz4
以提高備份效率。
start-fast=y間，特別是在數據變化不大的情況下。
delta=y

log-level-console=info
log-level-file=detail
log-path=/var/lib/pgbackrest/log

[main]
pg1-path=/bitnami/postgresql/data
pg1-socket-path=/tmp
pg1-user=postgres
pg1-port=5432
